# piogino.ch

Main website and hub for all projects. Static HTML/CSS, served by GitHub Pages from `main` (custom domain in `CNAME`); a push deploys it.

- `index.html`: start page with the project list
- `privacy.html`: privacy statement (Swiss FADP); update it and its date when the site changes
- `assets/`: stylesheet, theme switch, icon and self-hosted IBM Plex fonts (OFL)
