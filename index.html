About

I'm Pio Gino, a hobby developer. I build practical tools for problems I run into myself: sometimes because nothing fitting existed, sometimes because I wanted to understand how it works.

Most of it is written together with AI, Claude in particular, which made programming far more accessible to me. The code is on GitHub.
